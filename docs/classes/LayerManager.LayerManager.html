    Class LayerManager

    ゲームシーンのレイヤー管理を行うクラス

    主に、描画順の制御やRenderableEntityの所属レイヤー管理を目的として使用されます。 各レイヤーは LayerType に基づいて Container として自動生成され、 指定されたレイヤーにRenderableEntityを追加する機能を提供します。
